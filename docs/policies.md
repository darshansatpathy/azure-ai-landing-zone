## TFP001: Azure OpenAI and other Cognitive accounts must not accept public network traffic

**Severity:** critical  
**Reference:** MCSB NS-2

**Why it matters.** A public endpoint lets anyone who obtains a key or token reach the model from the internet.

**How to fix it.** Set public_network_access_enabled = false as a literal and reach the account through a private endpoint.

## TFP002: Cognitive accounts must disable key authentication

**Severity:** high  
**Reference:** MCSB IM-1

**Why it matters.** Static API keys cannot be scoped, rotated per caller or tied to a person, and leak in logs.

**How to fix it.** Set local_auth_enabled = false and grant callers a data-plane role through Microsoft Entra ID.

## TFP003: Cognitive accounts need a custom subdomain

**Severity:** medium  
**Reference:** MCSB IM-1

**Why it matters.** Microsoft Entra authentication and private endpoints both require a custom subdomain name.

**How to fix it.** Set custom_subdomain_name.

## TFP004: Key Vaults must have purge protection and soft delete retention

**Severity:** high  
**Reference:** MCSB DP-8

**Why it matters.** Without purge protection a deleted vault, and every key in it, can be destroyed permanently.

**How to fix it.** Set purge_protection_enabled = true and soft_delete_retention_days to at least 7.

## TFP005: Key Vaults must use Azure RBAC and be closed to the public network

**Severity:** high  
**Reference:** MCSB IM-1, NS-2

**Why it matters.** Access policies are not auditable per role, and an open vault firewall exposes secrets metadata.

**How to fix it.** Set rbac_authorization_enabled = true and public_network_access_enabled = false.

## TFP006: Storage accounts must be hardened

**Severity:** high  
**Reference:** MCSB DP-3, NS-2

**Why it matters.** Shared keys, anonymous blobs, old TLS and an open firewall are the common causes of data exposure.

**How to fix it.** Set min_tls_version = TLS1_2, allow_nested_items_to_be_public = false, shared_access_key_enabled = false, and close the public network or deny by default.

## TFP007: Private endpoints must register in a private DNS zone

**Severity:** medium  
**Reference:** MCSB NS-1

**Why it matters.** Without a DNS zone group the service name still resolves to its public address.

**How to fix it.** Add a private_dns_zone_group block with the matching privatelink zone.

## TFP008: Every PaaS data service must have a private endpoint in the same module

**Severity:** high  
**Reference:** MCSB NS-2

**Why it matters.** Disabling public access is only useful if callers have a private path to the service.

**How to fix it.** Add an azurerm_private_endpoint whose private_connection_resource_id references the resource.

## TFP009: Diagnostic settings must send logs and metrics to Log Analytics

**Severity:** medium  
**Reference:** MCSB LT-3

**Why it matters.** Without audit logs there is no evidence of who called the model or changed the vault.

**How to fix it.** Add an azurerm_monitor_diagnostic_setting targeting the resource with a Log Analytics workspace.

## TFP010: No credentials in code

**Severity:** critical  
**Reference:** MCSB IM-8

**Why it matters.** Secrets committed to a repository are leaked to everyone with read access, forever.

**How to fix it.** Use managed identities and Key Vault references. Never write a secret as a literal.

## TFP011: Variables must be typed and described, and secrets must be sensitive

**Severity:** low  
**Reference:** Terraform style guide

**Why it matters.** Untyped variables hide mistakes, and unmarked secrets are printed in plans and logs.

**How to fix it.** Add type and description; set sensitive = true on secret variables and outputs.

## TFP012: Terraform and provider versions must be constrained

**Severity:** medium  
**Reference:** Supply chain hygiene

**Why it matters.** Unpinned providers change behaviour between runs and break reproducible plans.

**How to fix it.** Set required_version and a versioned required_providers entry in every module.

## TFP013: Network security groups must not allow inbound traffic from the internet

**Severity:** high  
**Reference:** MCSB NS-1

**Why it matters.** An allow rule from any address exposes the subnet to scanning and brute force.

**How to fix it.** Restrict source_address_prefix to a service tag or a known range.

## TFP014: Every subnet needs a network security group

**Severity:** medium  
**Reference:** MCSB NS-1

**Why it matters.** A subnet without an NSG has no network-layer filtering at all.

**How to fix it.** Add an azurerm_subnet_network_security_group_association for the subnet.

## TFP015: Resources must carry the required tags

**Severity:** low  
**Reference:** Cloud Adoption Framework tagging

**Why it matters.** Tags drive cost allocation, ownership and data classification, and policy depends on them.

**How to fix it.** Set tags on every taggable resource and include the keys listed in tfpolicy.toml.

## TFP016: Model deployments must name a content filter policy

**Severity:** medium  
**Reference:** Responsible AI

**Why it matters.** Relying on the service default leaves the filtering level implicit and unreviewed.

**How to fix it.** Set rai_policy_name on every azurerm_cognitive_deployment.

## TFP017: Root modules must use a remote azurerm backend with Entra ID authentication

**Severity:** high  
**Reference:** MCSB DP-3, IM-1

**Why it matters.** Local state holds secrets and breaks locking, and storage keys give broad access to state.

**How to fix it.** Declare backend "azurerm" with use_azuread_auth = true.

## TFP018: Environment roots must apply the Azure Policy guardrails module

**Severity:** medium  
**Reference:** MCSB PV-2

**Why it matters.** Preventive policy stops a later change from reopening what Terraform closed.

**How to fix it.** Call the guardrails module from every root under envs/.

## TFP019: API Management must be network-isolated

**Severity:** high  
**Reference:** MCSB NS-1, NS-2

**Why it matters.** A public gateway in front of a private model is the new public endpoint.

**How to fix it.** Set virtual_network_type = "Internal" and inject the gateway into its own subnet.

## TFP020: Gateway policy must authenticate callers, limit tokens and use managed identity

**Severity:** high  
**Reference:** Responsible AI, MCSB IM-1

**Why it matters.** The gateway is where per-caller token budgets and keyless access to the model are enforced.

**How to fix it.** Include validate-jwt, llm-token-limit and authentication-managed-identity, and never forward an api-key header.

## TFP021: Private DNS zones must be linked to a virtual network

**Severity:** medium  
**Reference:** MCSB NS-1

**Why it matters.** An unlinked zone resolves nothing, so clients fall back to the public address.

**How to fix it.** Add an azurerm_private_dns_zone_virtual_network_link for the zone.

## TFP022: Role assignments must name a principal type and a built-in or custom role

**Severity:** low  
**Reference:** MCSB PA-7

**Why it matters.** An unset principal_type makes assignments slower to propagate and harder to audit.

**How to fix it.** Set principal_type to ServicePrincipal, User or Group, and avoid the Owner role.

## TFP023: Every reference must resolve

**Severity:** high  
**Reference:** Terraform validate

**Why it matters.** A reference to an undeclared variable, local, module output or resource fails at plan time, after the pipeline has already started.

**How to fix it.** Declare the variable, local, output or resource, or fix the name.

## TFP024: Module calls must pass every required variable and nothing else

**Severity:** high  
**Reference:** Terraform validate

**Why it matters.** A missing required argument or an unknown one is a plan-time error.

**How to fix it.** Pass each variable without a default, and remove arguments the module does not declare.
