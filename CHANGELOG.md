# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-13

### Added
- Terraform modules for network, observability, Key Vault, Azure OpenAI, API Management AI gateway and Azure Policy guardrails.
- `dev` and `prod` environment roots and a remote-state bootstrap.
- `tfpolicy`, a stdlib-only policy checker with 24 rules, SARIF output and a formatting check.
- Architecture, threat model, compliance mapping, runbook and six ADRs.
- CI with Terraform validation, CodeQL and a manual OIDC deploy workflow.
